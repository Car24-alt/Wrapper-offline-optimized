## What's New in This Fork?

This optimized version of Wrapper: Offline includes:

### ✨ New Features
- **Direct Video Export** - Export videos to MP4/WebM without screen recording
- **Performance Optimizations** - Faster rendering and reduced lag
- **Improved Memory Management** - Better resource usage
- **Build Optimizations** - Faster compilation and smaller bundle size

## Installation & Usage

### Development
```bash
npm install
npm run dev
```

### Build
```bash
npm run build
```

### Package
```bash
npm run package
```

## Original Project
Wrapper: Offline is a program designed to provide readily obtainable, irrevocable access to GoAnimate's retired assets in the modern era.
